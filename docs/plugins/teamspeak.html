teamspeak

Description

TeamSpeak plugin for bot_squared.

This plugin provides integration with TeamSpeak servers, allowing the bot to: - Send and receive messages - Monitor user activity - Manage channel names - Handle user joins and notifications - Move inactive users to AFK channel

Plugin Events

Methods that are triggered by the bot system in response to specific events.

Plugin Event

Arguments

Name Type Description

to int The target ID to send the message to

Returns

None: No description available.
